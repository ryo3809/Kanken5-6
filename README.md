# 漢検 6級・5級 学習アプリ

小学生が、iPad で毎日10〜15分ずつ漢字を練習して、
日本漢字能力検定（漢検）の **6級 → 5級** に合格することを目指すアプリです。

- **インターネットにつながっていなくても使えます**（飛行機の中でも動きます）
- **学習の記録は iPad の中だけに保存されます。外部には一切送りません**
- ログインも、会員登録も、広告も、課金もありません

## アプリの動かしかた

### パソコンで見る

```
npm install     ← 最初の1回だけ
npm run dev
```

画面に出てくる `http://localhost:5173/` をブラウザで開いてください。
**止めかた**：`Ctrl` キーを押しながら `C` キー。

### iPad で見る（同じ Wi-Fi につないでいるとき）

1. パソコンで `npm run dev` を実行する
2. 画面に `Network: http://192.168.x.x:5173/` のような行が出る
3. その住所を iPad の Safari で開く

※ パソコンと iPad が**同じ Wi-Fi** につながっている必要があります。
※ 出先でも使えるようにするのは、フェーズ7（インターネットに公開）でやります。

### 動くか自分で確かめる

```
npm test
```

漢字データの計算と、実際のブラウザでの操作を自動で確かめます。
`data/screenshots/` に画面の写真も残ります。

## 漢字データの作りなおしかた

### 準備（最初の1回だけ）

**Node.js** というソフトが必要です。パソコンでプログラムを動かすための土台です。

1. https://nodejs.org/ja を開く
2. 「LTS」と書かれた方をダウンロードしてインストールする
3. インストールできたか確認する（下の「ターミナルの開きかた」を見てください）

```
node --version
```

`v22.0.0` のような数字が出れば成功です。`v20` 以上なら大丈夫です。

### ターミナルの開きかた

「ターミナル」は、パソコンに文字で命令を出すための画面です。

- **Mac** … `command`キー + スペースキー →「ターミナル」と入力 → Enter
- **Windows** … スタートボタンを右クリック →「ターミナル」または「PowerShell」

開いたら、このアプリのフォルダに移動します。

```
cd （このフォルダの場所）
```

※ フォルダをターミナルの画面にドラッグ＆ドロップすると、場所が自動で入力されます。

### 漢字データを作りなおす

```
npm run data:all
```

この1行で、次の4つが順番に実行されます。

| コマンド | 何をするか | かかる時間 |
|---|---|---|
| `npm run data:fetch` | 元データをインターネットから取ってくる | 初回3分ほど／2回目以降は数秒 |
| `npm run data:build` | 1つにまとめて、アプリが使う形にする | 10秒ほど |
| `npm run data:verify` | 正しいか自動でチェックする | 5秒ほど |
| `npm run data:csv` | 目で校正するための CSV を書き出す | 3秒ほど |

**止めかた**：`Ctrl` キーを押しながら `C` キー。途中で止めてもデータは壊れません。

## 校正のしかた（大事）

間違った読みを覚えさせてしまうと、アプリが無い場合より有害です。
そのため、**出典がはっきりしないデータは、確認が済むまでアプリに出さない**しくみにしています。

`npm run data:csv` を実行すると、`data/csv/` フォルダに4つのファイルができます。

| ファイル | 中身 | いつ見るか |
|---|---|---|
| **3-いますぐ確認.csv** | 人の確認が必要なものだけ（15件） | **★まずこれ** |
| 1-漢字一覧.csv | 1026字ぜんぶ。読み・熟語・画数・部首 | ざっと眺める |
| 2-熟語一覧.csv | 出題に使う熟語ぜんぶ（よく使う順） | 気になったとき |
| 4-部首の校正シート.csv | 部首の確認用 | フェーズ1bで使う |

Excel や Numbers でそのまま開けます（文字化けしません）。

## 学習データの保存場所とバックアップ

### 漢字のデータ（アプリが出題に使うもの）

| 場所 | 中身 | Gitに保存 |
|---|---|---|
| `src/data/kanji.json` | 漢字1026字の情報 | ✅ する |
| `src/data/words.json` | 熟語 約2900語 | ✅ する |
| `public/strokes/grade-*.json` | 筆順データ | ✅ する |
| `data/cache/` | ネットから取ってきた元データ | ❌ しない（再取得できる） |
| `data/csv/` | 校正用のCSV | ✅ する |

**バックアップのしかた**：このフォルダ全体を、別の場所にコピーしてください。
（Mac なら `command`+`C` → 別の場所で `command`+`V`）
大きな変更をする前には、毎回コピーを取ることをおすすめします。

### 子どもの学習記録

iPad の中（**IndexedDB** ＝ ブラウザが端末内に持っている保存場所）にだけ保存されます。
**外には一切送られません。**パソコンのフォルダをコピーしても、学習記録はコピーされません。

⚠️ **iOS Safari には、ホーム画面に追加していないサイトのデータを7日間で消す仕様があります。**

そのため、次の2つを必ずやってください。

1. **iPad のホーム画面に追加する**
   Safari で開く → 画面下（または右上）の 共有ボタン → 「ホーム画面に追加」 → 「追加」
   （アプリの最初の画面に、この案内が自動で出ます）

2. **月に1回、バックアップを取る**
   アプリの「きろくの バックアップ」→「ファイルに 書き出す」
   → `かんじ-きろく-2026-08-29-18-26-02.json` のようなファイルができます
   → iPad の「ファイル」アプリに保存されるので、**iCloud Drive など iPad の外にもコピー**してください

戻すときは、同じ画面の「ファイルを えらんで 読みこむ」から。
（読みこむと、いまの記録は**置きかわります**。先に書き出しておくと安心です）

## 漢字データを直したいとき

### まず読むファイル

**`docs/kanken-spec.md`** … 出題形式・配点・合格ラインの根拠が全部書いてあります。
受検する年度が変わったら、公式サイトを見てこのファイルを更新してください。

### ファイルの役割

| ファイル | 何を直すときに触るか |
|---|---|
| `scripts/sources.mjs` | 元データの取得先が変わったとき |
| `scripts/build-kanji-data.mjs` | 熟語の選び方・データの形を変えたいとき |
| `scripts/verify-kanji-data.mjs` | チェック項目を増やしたいとき |
| `scripts/export-csv.mjs` | CSVの列を変えたいとき |
| `docs/kanken-spec.md` | 出題形式・配点が変わったとき |

**`src/data/kanji.json` を直接手で書きかえないでください。**
`npm run data:build` を実行すると上書きされて消えます。
直したいときは、上の「スクリプト」のほうを直してください。

## よくあるエラーと対処

### `npm: command not found` / `node: command not found`

Node.js がまだ入っていません。上の「準備」を見てインストールしてください。

### `インターネットからデータを取ってこられませんでした`

- インターネットにつながっているか確認してください
- 少し待って、もう一度 `npm run data:fetch` を実行してください
- 会社や学校の Wi-Fi だと、一部のサイトがブロックされていることがあります

### `元データが見つかりません`

先に `npm run data:fetch` を実行してください。

### `2つの出典で、漢字の学年が食い違っています`

元データの配布元で内容が変わった可能性があります。**この状態のデータは使わないでください。**
`docs/kanken-spec.md` を読み、文部科学省の学年別漢字配当表と照らし合わせてください。

### `【必須】の検証が N件 落ちました`

データに問題があります。画面に出ている漢字を確認してください。
まず `npm run data:fetch -- --force` で元データを取り直すと直ることが多いです。

### アプリを開いても「よみこんでいます…」から進まない

Safari の「プライベートブラウズ」だと記録の保存ができません。ふつうのタブで開いてください。
それでも直らないときは、Safari をいったん完全に閉じて開きなおしてください。

### 「きろくを ほぞんできません」と出る

- プライベートブラウズを使っていないか確認してください
- iPad の空き容量が少ないと出ることがあります（設定 → 一般 → iPadストレージ）

### iPad から `http://192.168...` が開けない

- パソコンと iPad が同じ Wi-Fi につながっているか確認してください
- パソコン側で `npm run dev` が動いたままか確認してください
- パソコンのファイアウォールがブロックしていることがあります

### CSVを開いたら文字化けする

Excel の場合、ファイルをダブルクリックせずに、
Excel を先に開いて「ファイル」→「開く」から選ぶと直ることがあります。
