# 漢検 6級・5級 学習アプリ

小学生が、iPad で毎日10〜15分ずつ漢字を練習して、
日本漢字能力検定（漢検）の **6級 → 5級** に合格することを目指すアプリです。

- **インターネットにつながっていなくても使えます**（飛行機の中でも動きます）
- **学習の記録は iPad の中だけに保存されます。外部には一切送りません**
- ログインも、会員登録も、広告も、課金もありません

**iPad で使えるようになりました。** 読み問題を10問といて、翌日にまちがえた漢字が復習に出るところまで動きます。

いまできること：
- 読み問題（4つから選ぶ／ひらがなで書く の2とおり）
- **なぞり書き（Apple Pencil・指の両方に対応。筆順・書きはじめ・向きを1画ずつ判定）**
- **書き取り（白紙に自分で書き、お手本を重ねて自己採点）**
- **柴犬「しばまる」／おさんぽマップ／かんじずかん／きせかえ／スタンプ**
- 間隔反復による自動復習（1日／2日／4日／7日／14日）
- 学習記録の保存（iPad の中だけ）
- 学習記録の JSON バックアップと復元
- 6級／5級の切りかえ

まだ無いもの：模擬試験・くわしい保護者画面（フェーズ6以降）

### しばまるとごほうび要素

- **しばまる**（オリジナルの柴犬）が相棒として全体に出ます。表情は6種類
- **正解すると喜び、まちがえても励まします。**責めたり悲しませたりする演出は入れていません
  （まちがえても経験値はもらえます。自動テストで確認しています）
- **おさんぽマップ**：学習量に応じて12か所を進み、ゴールごとに風景とごほうびがもらえます
- **かんじずかん**：れんしゅうした漢字に色がつきます。タップすると筆順アニメが見られます
- **きせかえ**：ぼうし4種・くびわ4種。おさんぽマップでもらえます
- **スタンプ**：がんばった日にスタンプが押されます。**休んでも消えません**

**「連続日数」ではなく「がんばった日（累計）」を主役にしています。**
1日休んだだけでゼロになる表示は、続ける気持ちを折るためです。

キャラクターの絵を描きかえたいときは `src/character/README.md` を読んでください。

### 書き取り（自己採点）について

本番の検定と同じ出し方です。「**ゼイ金**」のように、書かせたい漢字だけがカタカナになります。

1. 白紙のマスに、自分の力で漢字を書く（お手本は出ません）
2. 「こたえを見る」を押すと、正しい字が**うすいむらさきで自分の字に重なって**出る
3. 見くらべて「できた／おしい／まちがえた」を自分で選ぶ
4. 「おしい／まちがえた」を選んだ字は、**あした復習に出ます**

書き間違えたときは「1かく もどす」で1画ずつ消せます。

**自己採点の結果は、保護者が「きろくの バックアップ」画面で確認できます。**
「できた」の割合が高すぎるときは、画面に注意が出ます。

### 分野ごとのデータの出どころ

| 分野 | 出どころ | 確認 |
|---|---|---|
| 読み・書き取り | 常用漢字表／国語辞典(JMdict) | 不要 |
| 筆順・画数 | KanjiVG | 不要 |
| **部首・部首名** | KANJIDIC2（康熙214部首）＋『漢検漢字辞典』の部首名 | 1017字は不要／9字は要確認 |
| **三字熟語** | 国語辞典(JMdict)＋使用頻度 | 不要 |
| **四字熟語** | 国語辞典(JMdict)の「四字熟語」分類 | 不要 |
| **対義語・類義語** | 語は辞典／**関係はAIの判断** | **全件 要確認** |
| **熟語の構成** | 語は辞典／**分類（ア〜エ）はAIの判断** | **全件 要確認** |

⚠️ **部首について**：出どころは KANJIDIC2（康熙214部首）で、名前は『漢検漢字辞典』の部首一覧です。
**漢検の部首分類と一致しない字がある可能性は残ります。**
お子さんの問題集と見くらべて、ちがう字があれば `data/approvals/2-部首.csv` に書いてください。

### 練習する漢字の順番

**学年の高いほうから練習します。**

- 6級 → 5年配当（この級の新出範囲）→ 4年 → 3年 → 2年 → 1年
- 5級 → 6年配当 → 5年 → …

受検するのが小学5・6年生なので、1年生の「一」から始めても練習になりません。
やさしい漢字は、まちがえたときに復習のしくみが拾ってくれます。

順番を変えたいときは `src/lib/questions.ts` の `charsForKyu` を直すと、
読み問題・書き取り・なぞり書きのすべてに反映されます。

### なぞり書きについて

- お手本の上をなぞると、**1画ごとに**「書きはじめの場所」「書く向き」「画の順番」を自動で判定します
- **AIは使っていません。**すべて計算だけで判定しているので、オフラインでも動き、費用もかかりません
- まちがえたときは**その画だけ**やり直します（最初からにはしません）
- Apple Pencil を使っているあいだは、手のひらが画面に触れても無視します（1.5秒たつと指でも書けるようになります）
- なぞり書きは「おぼえるための練習」なので、**読みの復習（箱1〜5）は動かしません**。
  書く力を測るのはフェーズ4の「書き取り（自己採点）」です

## 漢字データの作りなおしかた

### 準備（最初の1回だけ）

**Node.js** というソフトが必要です。パソコンでプログラムを動かすための土台です。

1. https://nodejs.org/ja を開く
2. 「LTS」と書かれた方をダウンロードしてインストールする
3. インストールできたか確認する（下の「ターミナルの開きかた」を見てください）

```
node --version
```

`v22.0.0` のような数字が出れば成功です。`v20` 以上なら大丈夫です。

### ターミナルの開きかた

「ターミナル」は、パソコンに文字で命令を出すための画面です。

- **Mac** … `command`キー + スペースキー →「ターミナル」と入力 → Enter
- **Windows** … スタートボタンを右クリック →「ターミナル」または「PowerShell」

開いたら、このアプリのフォルダに移動します。

```
cd （このフォルダの場所）
```

※ フォルダをターミナルの画面にドラッグ＆ドロップすると、場所が自動で入力されます。

### 漢字データを作りなおす

```
npm run data:all
```

この1行で、次の4つが順番に実行されます。

| コマンド | 何をするか | かかる時間 |
|---|---|---|
| `npm run data:fetch` | 元データをインターネットから取ってくる | 初回3分ほど／2回目以降は数秒 |
| `npm run data:build` | 1つにまとめて、アプリが使う形にする | 10秒ほど |
| `npm run data:verify` | 正しいか自動でチェックする | 5秒ほど |
| `npm run data:csv` | 目で校正するための CSV を書き出す | 3秒ほど |

**止めかた**：`Ctrl` キーを押しながら `C` キー。途中で止めてもデータは壊れません。

## 校正のしかた（大事）

間違った読みを覚えさせてしまうと、アプリが無い場合より有害です。
そのため、**出典がはっきりしないデータは、確認が済むまでアプリに出さない**しくみにしています。

`npm run data:csv` を実行すると、`data/csv/` フォルダに4つのファイルができます。

| ファイル | 中身 | いつ見るか |
|---|---|---|
| **3-いますぐ確認.csv** | 人の確認が必要なものだけ（15件） | **★まずこれ** |
| 1-漢字一覧.csv | 1026字ぜんぶ。読み・熟語・画数・部首 | ざっと眺める |
| 2-熟語一覧.csv | 出題に使う熟語ぜんぶ（よく使う順） | 気になったとき |
| 4-部首の校正シート.csv | 部首の確認用 | フェーズ1bで使う |

Excel や Numbers でそのまま開けます（文字化けしません）。

## 学習データの保存場所とバックアップ

### 承認のしくみ（大事）

出どころがはっきりしないデータは、**保護者が確認するまでアプリに出しません。**

確認は `data/approvals/` にある4つのCSVで行います。

| ファイル | 中身 | いまの状態 |
|---|---|---|
| `1-熟語の読み.csv` | 辞典から補った熟語の読み | 15件中13件 承認ずみ |
| `2-部首.csv` | ほかの出典と照合できなかった部首 | 9件 未確認 |
| `3-対義語・類義語.csv` | 対義語・類義語の組 | 75組 未確認 |
| `4-熟語の構成.csv` | 熟語の構成（ア〜エ） | 142語 未確認 |

**やりかた**

1. Excel などでCSVを開く
2. 内容が正しければ「**承認**」の列に `OK` と書く（ちがえば正しい内容をメモ欄に書く）
3. `npm run data:build` を実行すると、アプリに出るようになります

すでに書いた `OK` は、あとから `npm run data:csv` を実行しても消えません。
また、内容が変わった場合は承認が自動で外れ、もう一度確認できるようになります。

### 漢字のデータ（アプリが出題に使うもの）

| 場所 | 中身 | Gitに保存 |
|---|---|---|
| `src/data/kanji.json` | 漢字1026字の情報 | ✅ する |
| `src/data/words.json` | 熟語 約2900語 | ✅ する |
| `public/strokes/grade-*.json` | 筆順データ | ✅ する |
| `data/cache/` | ネットから取ってきた元データ | ❌ しない（再取得できる） |
| `data/csv/` | 校正用のCSV | ✅ する |
| `data/approvals/` | 承認ファイル（4つ） | ✅ する |
| `data/manual/` | AIが作った対義語・熟語の構成のもとデータ | ✅ する |

**バックアップのしかた**：このフォルダ全体を、別の場所にコピーしてください。
（Mac なら `command`+`C` → 別の場所で `command`+`V`）
大きな変更をする前には、毎回コピーを取ることをおすすめします。

### 子どもの学習記録

iPad の中（**IndexedDB** ＝ ブラウザが端末内に持っている保存場所）にだけ保存されます。
**外には一切送られません。**パソコンのフォルダをコピーしても、学習記録はコピーされません。

⚠️ **iOS Safari には、ホーム画面に追加していないサイトのデータを7日間で消す仕様があります。**

そのため、次の2つを必ずやってください。

1. **iPad のホーム画面に追加する**
   Safari で開く → 画面下（または右上）の 共有ボタン → 「ホーム画面に追加」 → 「追加」
   （アプリの最初の画面に、この案内が自動で出ます）

2. **月に1回、バックアップを取る**
   アプリの「きろくの バックアップ」→「ファイルに 書き出す」
   → `かんじ-きろく-2026-08-29-18-26-02.json` のようなファイルができます
   → iPad の「ファイル」アプリに保存されるので、**iCloud Drive など iPad の外にもコピー**してください

戻すときは、同じ画面の「ファイルを えらんで 読みこむ」から。
（読みこむと、いまの記録は**置きかわります**。先に書き出しておくと安心です）

## よくあるエラーと対処

### `npm: command not found` / `node: command not found`

Node.js がまだ入っていません。上の「準備」を見てインストールしてください。

### `インターネットからデータを取ってこられませんでした`

- インターネットにつながっているか確認してください
- 少し待って、もう一度 `npm run data:fetch` を実行してください
- 会社や学校の Wi-Fi だと、一部のサイトがブロックされていることがあります

### `元データが見つかりません`

先に `npm run data:fetch` を実行してください。

### `2つの出典で、漢字の学年が食い違っています`

元データの配布元で内容が変わった可能性があります。**この状態のデータは使わないでください。**
`docs/kanken-spec.md` を読み、文部科学省の学年別漢字配当表と照らし合わせてください。

### `【必須】の検証が N件 落ちました`

データに問題があります。画面に出ている漢字を確認してください。
まず `npm run data:fetch -- --force` で元データを取り直すと直ることが多いです。

### アプリを開いても「よみこんでいます…」から進まない

Safari の「プライベートブラウズ」だと記録の保存ができません。ふつうのタブで開いてください。
それでも直らないときは、Safari をいったん完全に閉じて開きなおしてください。

### 「きろくを ほぞんできません」と出る

- プライベートブラウズを使っていないか確認してください
- iPad の空き容量が少ないと出ることがあります（設定 → 一般 → iPadストレージ）

### iPad から `http://192.168...` が開けない

- パソコンと iPad が同じ Wi-Fi につながっているか確認してください
- パソコン側で `npm run dev` が動いたままか確認してください
- パソコンのファイアウォールがブロックしていることがあります

### なぞり書きで、ちゃんとなぞっているのに「まちがい」と出る

- お手本（こい色の線）の上を、**光っている ● から**なぞってください
- 線が短すぎると「せんが みじかすぎるよ」と出ます
- それでも合わないときは、判定のきびしさを `src/lib/tracing.ts` の `THRESHOLD` で調整できます
  （数字を大きくするとゆるく、小さくするときびしくなります）

### なぞり書きで、指で書けない

Apple Pencil を使った直後、1.5秒間は指の入力を無視します（手のひらの誤検知を防ぐため）。
少し待ってから指で書いてください。

### CSVを開いたら文字化けする

Excel の場合、ファイルをダブルクリックせずに、
Excel を先に開いて「ファイル」→「開く」から選ぶと直ることがあります。
