# 手で用意したデータについて

このフォルダのデータは、**公開されている出典が見つからなかった分野**のものです。
AI（Claude）が作成しました。

## だから、必ず保護者の確認が必要です

ここにあるデータは、**確認が済むまでアプリに出ません。**
確認は `data/approvals/` のCSVで行います。

## ただし、使っている語そのものは出典があります

たとえば「増加 ⇔ 減少」という対義語のペアなら、

- 「増加」「減少」という**語そのものと読み**は、国語辞典や常用漢字表から取っています（出典あり）
- 「この2語が対義語である」という**関係だけ**が、AIの判断です（要確認）

同じように「熟語の構成」も、語は出典つきで、**分類（ア〜エ）だけ**が要確認です。

確認していただくのは「関係・分類が正しいか」だけで済みます。
