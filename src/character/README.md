# しばまるの絵について

このフォルダに、**キャラクターの絵に関するものが全部まとまっています。**
絵を描きかえたいときは、ここだけを見れば大丈夫です。

## ファイルの役割

| ファイル | 中身 |
|---|---|
| `Shibamaru.tsx` | しばまるの絵そのもの（SVG）。丸を組みあわせて描いています |
| `expressions.ts` | 表情6種類の定義と、しばまるが言うことば |
| `items.ts` | きせかえアイテム（ぼうし4種・くびわ4種） |
| `Scene.tsx` | おさんぽマップの風景12種類 |

## 著作権について

**しばまるは、このアプリのために描いたオリジナルのキャラクターです。**
豆しばなど、既存の商用キャラクターは一切使っていません。
インターネットから拾った画像も使っていません。すべて図形（丸・線）の組みあわせです。

## 絵を描きかえたいとき

### 表情を変える

`expressions.ts` の `FACES` で、目と口の形を選んでいます。

```
happy: { eyes: 'arc', mouth: 'open', blush: true, wag: true }
         ↑目の形      ↑口の形        ↑ほっぺ    ↑しっぽをふる
```

目の形は `dot`（点）／`arc`（にっこり）／`sparkle`（きらきら）／
`closed`（とじる）／`wide`（まんまる）から選べます。
口の形は `small`／`open`／`smile`／`wave` から選べます。

### 言うことばを変える

`expressions.ts` の `LINES` を直してください。

**⚠️ 責めたり、悲しませたりすることばは入れないでください。**
自動テスト（`npm run test:game`）が、そういうことばが入っていないかを確認します。

### 絵をまるごと差しかえる

`Shibamaru.tsx` の中の SVG を書きかえてください。
外から呼ばれるときの決まりは次のとおりです。これさえ守れば、ほかのファイルは直さなくて済みます。

```
<Shibamaru expression="happy" hat="hat-straw" collar="collar-red" size={120} />
```

- 座標は 100×100 のマス目
- `className="shiba"` を付けると、しっぽをふるアニメが効きます
- `aria-label` を付けてください（目の見えにくい人のため）

### 見た目を確かめる

```
node scripts/test/shiba-sheet.mjs
```

全表情・全アイテムを1枚にした絵が `data/screenshots/shiba-sheet.png` に出ます。
描きかえたあとは、これで崩れていないか確認してください。
