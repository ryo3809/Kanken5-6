# 漢検 6級・5級 出題仕様（このアプリの実装根拠）

このファイルは、アプリの出題形式・配点を決める**唯一の根拠**です。
問題の作り方を変えたくなったら、まずここを読んでください。

- 最終確認日：2026-08-29
- 確認方法：公益財団法人 日本漢字能力検定協会 公式サイト「各級の概要」の内容を
  利用者（保護者）が閲覧して転記／公式配布の「試験問題見本」PDF を目視確認
- ※ 開発環境から kanken.or.jp へ直接アクセスできないため、AI が自動で再確認することは
  できません。**受検年度が変わったら、保護者が公式サイトを見て、このファイルを更新してください。**

## 1. 級のレベルと合格基準（出典：公式サイト「各級の概要」）

| | 6級 | 5級 |
|---|---|---|
| レベル | 小学校5年生修了程度 | 小学校6年生修了程度 |
| 対象漢字数 | 835字 | 1026字 |
| 満点 | 200点 | 200点 |
| 合格 | 70%程度 | 70%程度 |

「70%程度」＝ 200点満点なので **140点前後**。
公式表記は「程度」なので、合否ラインは回によって多少上下しうる。
→ アプリでは **140点を目標ライン**として表示し、「合格ラインの目安」と明記する。

### 審査基準（公式サイトの文言）

**6級**
- 程度：小学校第5学年までの学習漢字を理解し、文章の中で漢字が果たしている役割を知り、正しく使える。
- 《読むことと書くこと》小学校学年別漢字配当表の第5学年までの学習漢字を読み、書くことができる。
  - 音読みと訓読みとを正しく理解していること
  - 送り仮名や仮名遣いに注意して正しく書けること（求める、失う など）
  - 熟語の構成を知っていること（上下、絵画、大木、読書、不明 など）
  - 対義語、類義語の大体を理解していること（禁止－許可、平等－均等 など）
  - 同音・同訓異字を正しく理解していること
- 《筆順》筆順、総画数を正しく理解している。
- 《部首》部首を理解している。

**5級**
- 程度：小学校第6学年までの学習漢字を理解し、文章の中で漢字が果たしている役割に対する知識を身に付け、漢字を文章の中で適切に使える。
- 《読むことと書くこと》小学校学年別漢字配当表の第6学年までの学習漢字を読み、書くことができる。
  - 音読みと訓読みとを正しく理解していること
  - 送り仮名や仮名遣いに注意して正しく書けること
  - 熟語の構成を知っていること
  - 対義語、類義語を正しく理解していること
  - 同音・同訓異字を正しく理解していること
- 《四字熟語》四字熟語を正しく理解している（有名無実、郷土芸能 など）。
- 《筆順》筆順、総画数を正しく理解している。
- 《部首》部首を理解し、識別できる。

### 主な出題内容（公式サイトの列挙順）

- **6級**：漢字の読み／漢字の書取／部首・部首名／筆順・画数／送り仮名／対義語・類義語／同音・同訓異字／三字熟語／熟語の構成
- **5級**：漢字の読み／漢字の書取／部首・部首名／筆順・画数／送り仮名／対義語・類義語／同音・同訓異字／誤字訂正／四字熟語／熟語の構成

## 2. 実際の大問構成と配点

※ 問題そのものは著作物なので、このアプリには一切転載しない。
   ここに記録するのは「大問の並び・問題数・配点」という事実のみ。

### ⚠️ 未確定・要注意の事項

1. **5級の「誤字訂正」**
   公式の「主な出題内容」には誤字訂正が挙がっているが、
   2024年度第3回の実際の問題には誤字訂正の大問がなかった。
   → アプリの模試は上の実際の構成（11大問）を標準とし、
     誤字訂正は「分野べつれんしゅう」でのみ扱う。
   → 別の回の問題見本が手に入ったら、この項目を再確認すること。

2. **6級の(八)が6問、(十)が9問**
   他の大問と違って半端な数だが、問題用紙に印字された配点
   （(12) 2×6、(18) 2×9）のとおり。合計が正確に200点になることで裏取り済み。

3. **検定時間**
   問題用紙にも「各級の概要」にも記載を確認できていない。
   一般には5級・6級とも60分とされているため、アプリは **60分** を採用するが、
   **公式で未確認**。受検票などで確認できたらここを更新すること。

4. **答え方のルール（問題用紙の指示文より）**
   - 「答えには、『常用漢字表』にある漢字の字体を使うこと。旧字体を使ってはいけない。」
   - 読みの解答はひらがな。
   → アプリの読み問題も、ひらがな入力／常用漢字表の音訓のみを正解とする。

## 3. アプリの出題範囲の決め方

- **6級** … 学年別漢字配当表の 第1〜5学年（累計 835字）
- **5級** … 学年別漢字配当表の 第1〜6学年（累計 1026字）

「新出範囲」（その級で初めて対象になる漢字）は
- 6級 = 第5学年配当の 193字
- 5級 = 第6学年配当の 191字

例文・熟語には、**その級の対象外の漢字を使わない**（検証スクリプトで自動チェック）。
