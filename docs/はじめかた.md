# はじめかた（Mac・プログラムを入れずに使う）

このアプリを、iPad で毎日使えるようにするまでの手順です。
**パソコンにプログラムを入れる必要はありません。**
ブラウザとファイル操作だけで終わります。

かかる時間：**30分ほど**（アカウント作成をふくむ）

---

## 全体の流れ

```
1. ファイル一式を受けとる（Mac）      … 5分
2. Cloudflare にアカウントを作る（Mac）… 10分
3. ファイルを置く（Mac）              … 5分
4. iPad のホーム画面に追加する（iPad） … 5分
5. 動くか確かめる（iPad）             … 5分
```

---

## 1. ファイル一式を受けとる

`kanji-app.zip` を Mac にダウンロードします。

1. ダウンロードした `kanji-app.zip` を **ダブルクリック**する
2. `kanji-app` というフォルダができる
3. そのフォルダを開いて、中に `index.html` があることを確認する

> ⚠️ ここで「フォルダの中にもう1つフォルダがある」状態になっていたら、
> 内側のフォルダを使ってください。`index.html` がすぐ見えるフォルダが正解です。

---

## 2. Cloudflare にアカウントを作る

アプリを置く場所です。**無料・期限なし・広告なし・クレジットカード不要**です。

1. Safari で https://dash.cloudflare.com/sign-up を開く
2. メールアドレスとパスワードを入れて「Sign Up」
3. 届いたメールの中のリンクを押して、登録を完了する
4. プランを聞かれたら **Free（無料）** を選ぶ

> 英語の画面ですが、押すところは決まっています。次で説明します。

---

## 3. ファイルを置く

1. Cloudflare の画面の**左のメニュー**から **「Workers & Pages」** を選ぶ
   （「Compute」の中にある場合もあります）
2. **「Create application」** ボタンを押す
3. 上のタブで **「Pages」** を選ぶ
4. **「Upload assets」**（アセットをアップロード）を選ぶ
5. **プロジェクト名**を入れる。ここで入れた名前がそのまま住所になります
   - 例：`kanji-renshu` と入れると `kanji-renshu.pages.dev` になります
   - 人に知られたくない場合は、`kanji-8x2k9m` のように推測しにくい名前にしてください
6. **手順1でできた `kanji-app` フォルダを、そのまま画面にドラッグして落とす**
   - フォルダごとで大丈夫です。中身が自動で読みこまれます
7. **「Deploy site」** を押す

30秒ほどで「Success!」と出て、`https://〇〇.pages.dev` という住所が表示されます。
**この住所をメモしてください。**（自分あてにメールしておくと iPad で開きやすいです）

---

## 4. iPad のホーム画面に追加する【いちばん大事】

**ここを飛ばすと、iPad が7日で学習記録を消してしまいます。**

1. iPad の **Safari** で、手順3の住所を開く
   （Chrome など他のブラウザではダメです。Safari で開いてください）
2. 画面の上のほうにある **共有ボタン**（□ に ↑ のマーク）を押す
3. メニューを下にスクロールして **「ホーム画面に追加」** を押す
4. 右上の **「追加」** を押す
5. ホーム画面に、柴犬のアイコンができます

**これ以降は、必ずこのアイコンから開いてください。**

### できたか確かめる

アプリを開いて、下のほうの **「おうちの人の がめん」** を押します。
一番上が

> **1. ホーム画面に追加できているか**
> できています。この状態なら、iPad が勝手に記録を消すことはありません。

になっていれば成功です。
「まだできていません」と赤く出ている場合は、Safari のタブから開いています。
ホーム画面のアイコンから開き直してください。

---

## 5. 動くか確かめる

1. アプリを一度ふつうに使う（「きょうの がくしゅう」を1回やってみる）
2. iPad を **機内モード**（電波を切る）にする
3. ホーム画面のアイコンから、もう一度アプリを開く
4. ふつうに開いて、なぞりがきまでできれば成功です

これができれば、電車の中でも、Wi-Fi のない場所でも使えます。

---

## 6. 最初にやっておくこと

アプリの「おうちの人の がめん」→ **「ファイルに 書き出す」** を1回押してください。
`かんじ-きろく-2026-〇〇-〇〇.json` というファイルができます。

このファイルを **iCloud Drive** など、iPad の外にも残る場所にコピーしておいてください。
月に1回でよいので、これを続けてください。**記録を取り戻せる唯一の方法です。**

---

## アプリを新しくしたいとき

新しい `kanji-app.zip` を受けとったら、

1. Cloudflare の画面で、作ったプロジェクトを開く
2. **「Create deployment」** を押す
3. 新しいフォルダをドラッグして **「Deploy」**

iPad 側では、次にアプリを開いたときに
**「あたらしい バージョンが あります」**と出ます。
「あたらしくする」を押すと切りかわります。**学習の記録はそのまま残ります。**

---

## 承認CSVの作業をしたいとき

模擬試験を200点満点にするための承認作業（226件）には、2つのやり方があります。

**やり方A：作業を頼む（おすすめ・準備不要）**
承認シート（`きょうの承認シート.csv`）を受けとって、Excel や Numbers で
「承認」の欄に `OK` と書いて送り返す。あとの処理と新しい zip の用意は、
こちらでやります。パソコンに何も入れる必要はありません。

**やり方B：自分でやる（プログラムを入れる）**
Mac に Node.js を入れて、自分でコマンドを実行します。
手順は `README.md` の「承認のしくみ」を見てください。

## 困ったときは

| こうなった | こうする |
|---|---|
| Cloudflare の画面で「Upload assets」が見つからない | 「Create application」→ 上のタブで「Pages」を選んでいるか確認 |
| ドラッグしても反応しない | フォルダではなく zip のまま落としていませんか。先にダブルクリックで開いてください |
| iPad で真っ白になる | アプリを閉じて開き直す。それでもダメなら Safari で住所を直接開く |
| 「ホーム画面に追加」が出ない | Safari で開いていますか。Chrome では出ません |
| 記録が消えた | 「おうちの人の がめん」→「読みこむ」で、書き出した JSON から戻せます |
| 機内モードで開けない | 一度電波のある場所でアイコンから開き直してください（そのとき保存されます） |
