# iPad で毎日使えるようにする手順（公開のしかた）

このファイルは、**パソコンを立ち上げなくても iPad だけでアプリを使える**ようにするための手順です。
プログラムの知識は要りません。上から順に進めてください。

所要時間：はじめてなら 30分ほど。2回目からは 5分です。

---

## この作業でやること

いまは、パソコンで `npm run dev` を動かしている間だけ iPad から使える状態です。
これを、**インターネット上の決まった住所（URL）に置く**ことで、
パソコンなしで、いつでも iPad から開けるようにします。

置き場所には **Cloudflare Pages**（クラウドフレア・ページズ）を使います。無料です。

### なぜ Cloudflare Pages なのか

- 無料で、期限もありません
- 広告が入りません
- クレジットカードの登録が要りません
- URL を知っている人だけが開けます（検索には出さない設定にします）

### 大事なこと：それでも記録は外に出ません

置き場所に置くのは、**アプリのプログラムだけ**です。
お子さんの学習記録（どの漢字を間違えたか、模試の点数、書いた字）は、
**iPad の中だけに保存され、Cloudflare にも、どこにも送られません。**

さらに、`public/_headers` というファイルで
「このアプリは自分自身のファイル以外、どこにも通信してはいけない」という命令を
ブラウザに出しています。万一プログラムに間違いがあっても、記録は外に出ません。

---

## 手順1：アプリのファイルを作る

パソコンで、このフォルダを開いて、次を実行します。

```
npm install
npm run build
```

`dist` というフォルダができます。この中身が、置き場所にアップするものです。

> うまくいかないときは、画面に出た日本語のメッセージを読んでください。
> 「どうすればいい？」の欄に、次にすることが書いてあります。

---

## 手順2：Cloudflare のアカウントを作る

1. https://dash.cloudflare.com/sign-up をブラウザで開く
2. メールアドレスとパスワードを入れて登録する
3. 届いたメールのリンクを押して、登録を完了する

クレジットカードは要りません。求められたら、無料プラン（Free）を選んでください。

---

## 手順3：アプリを置く

いちばんかんたんな「ファイルをドラッグして置く」方法で説明します。

1. Cloudflare の画面の左側で **Workers & Pages** を選ぶ
2. **Create application** → **Pages** → **Upload assets** を選ぶ
3. プロジェクト名を入れる（例：`kanji-renshu`）
   - ここで入れた名前が、そのまま URL になります
   - `kanji-renshu.pages.dev` のような住所になります
4. 手順1で作った **`dist` フォルダの中身**を、まとめてドラッグして入れる
   - ⚠️ `dist` フォルダそのものではなく、**中身**（index.html などが並んでいるもの）です
5. **Deploy site** を押す

数十秒で「Success!」と出て、URL が表示されます。この URL をメモしてください。

---

## 手順4：iPad のホーム画面に追加する（いちばん大事）

**ここを飛ばすと、iPad が7日で学習記録を消してしまいます。**

1. iPad の Safari で、手順3の URL を開く
2. 画面の **共有ボタン**（□に↑のマーク）を押す
3. メニューを下にスクロールして **「ホーム画面に追加」** を押す
4. 右上の **「追加」** を押す
5. ホーム画面に、柴犬のアイコンができます

**これ以降は、必ずこのアイコンから開いてください。**
Safari のタブから開くと、記録が別あつかいになってしまいます。

うまくできたかは、アプリの中で確かめられます。
「おうちの人の がめん」を開いて、
**「1. ホーム画面に追加できているか」→「できています」** になっていれば成功です。

---

## 手順5：確かめる

1. iPad を**機内モード**にする（電波を切る）
2. ホーム画面のアイコンからアプリを開く
3. ふつうに開いて、なぞりがきまでできれば成功です

これができれば、電車の中や、Wi-Fi のない場所でも使えます。

---

## アプリを新しくしたとき

プログラムを直したら、もう一度これをします。

1. `npm run build` を実行する
2. Cloudflare の同じプロジェクトを開く → **Create deployment** → `dist` の中身をドラッグ → **Deploy**

iPad 側では、次にアプリを開いたときに
**「あたらしい バージョンが あります」**という案内が出ます。
「あたらしくする」を押すと切りかわります。**学習の記録はそのまま残ります。**

> 勝手に切りかわらないようにしてあります。
> お子さんが問題を解いている最中に画面が入れかわる、ということは起きません。

---

## URL を人に知られたくないとき

このアプリは「URL を知っている人だけが見られればよい」という方針で作っています。

- URL は検索エンジンには載りにくいですが、**絶対に載らないとは限りません**
- 気になる場合は、プロジェクト名を推測されにくいものにしてください
  （例：`kanji-renshu` ではなく `kanji-8x2k9m` のようにする）
- アプリの中に、お子さんの名前や写真は一切入っていません。
  学習記録も端末の中だけなので、万一 URL を知られても、記録が見られることはありません

---

## 困ったときは

| こうなった | こうする |
|---|---|
| ビルドで止まる | 画面の日本語メッセージの「どうすればいい？」を読む |
| iPad で真っ白になる | 一度アプリを閉じて開き直す。それでもダメなら Safari で URL を直接開く |
| 「ホーム画面に追加」が出ない | Safari で開いていますか？ Chrome など他のブラウザでは出ません |
| 記録が消えた | 「おうちの人の がめん」→「読みこむ」で、書き出しておいた JSON ファイルから戻せます |
| 電波なしで開けない | ホーム画面のアイコンから一度オンラインで開き直してください（そのとき保存されます） |
